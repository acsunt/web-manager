# 网页管理系统

书签和网页管理工具，浏览器里可以直接用，也可以安装 Android APK。

## 下载

到 [Releases](https://github.com/acsunt/web-manager/releases/latest) 按文件名选择：

- `wan-vX.Y.Z-yes.html`：需联网加载 Font Awesome / Cropper / Sortable / JSZip
- `wan-vX.Y.Z-no.html`：依赖已内联，可离线双击打开
- `web-manager-vX.Y.Z-32.apk`：Android 32 位安装包（armeabi-v7a），内置离线网页
- `web-manager-vX.Y.Z-64.apk`：Android 64 位安装包（arm64-v8a），内置离线网页
